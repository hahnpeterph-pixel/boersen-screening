# Kursluecken je Wert

_Mindestgroesse 0.1 ATR. Als 'reif' gilt eine Luecke ab 21 Handelstagen Alter - nur reife Luecken gehen in die Schliessquote ein._

Aufwaerts- und Abwaerts-Luecken werden getrennt ausgewiesen: eine Aufwaerts-Luecke schliesst sich, wenn der Kurs FAELLT (Risiko fuer eine Long-Position), eine Abwaerts-Luecke, wenn er STEIGT (Kursziel fuer eine Long-Position). Beides zusammenzuwerfen verwischt genau diesen Unterschied.
